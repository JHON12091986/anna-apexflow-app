# ApexFlow - AI Workflow Automator

ApexFlow is a FastAPI-based application designed to automate and manage AI workflows. 

## Features
- RESTful API to trigger automated tasks.
- Built with Python and FastAPI.
- Ready to be deployed via Docker for cross-platform compatibility (Windows, macOS, Linux).

## How to run
1. Install dependencies: `pip install -r requirements.txt`
2. Run the server: `uvicorn main:app --reload`
3. Access the API docs at `http://localhost:8000/docs`
